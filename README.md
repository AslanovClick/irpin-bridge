# IRPIN BRIDGE — сайт та інтернет-магазин

Сайт креативної студії IRPIN BRIDGE (соціальне підприємство БФ «Єдність світу», Ірпінь): магазин мерчу, кастомізація одягу, бізнес-мерч, послуги друку й вишивки, арт-мерч, сторінки про студію.

**Стан:** фронтенд-превʼю для погодження. Бекенду ще немає — товари, замовлення й заявки працюють на демо-даних у браузері (localStorage), оплата й Нова пошта змодельовані.

## Стек

Next.js 16 (App Router), React 19, TypeScript, CSS Modules. Без сторонніх UI-бібліотек.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # продакшн-збірка
npm start        # запуск збірки
npm run lint
```

## Змінні оточення

Скопіюйте `.env.example` у `.env.local` (або задайте в налаштуваннях хостингу):

| Змінна | Призначення |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Адреса сайту для sitemap, canonical, schema.org |
| `NEXT_PUBLIC_GA_ID` | Google Analytics 4 (вантажиться лише після згоди на cookies) |
| `NEXT_PUBLIC_META_PIXEL_ID` | Meta Pixel (вантажиться лише після згоди на cookies) |

Усі змінні необовʼязкові: без них сайт працює, аналітика просто вимкнена.

## Деплой

Звичайний Next.js-проєкт — розгортається на Vercel без додаткових налаштувань (Framework: Next.js, корінь репозиторію). Для превʼю радимо виставити `NEXT_PUBLIC_SITE_URL` на адресу превʼю.

## Структура

```
src/app         сторінки (маршрути)
src/components  компоненти за розділами
src/data        демо-дані: товари, колекції, митці, послуги, юр. документи
src/lib         кошик, заявки, згода на cookies, аналітика
src/styles      дизайн-токени й теми
public          логотипи й фото-заглушки
```

Сторінка `/styleguide` — дизайн-система (кольори, типографіка, компоненти), закрита від індексації.
